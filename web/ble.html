AutoTest

Runs by itself every time the port gets an address. Checks the link, DHCP, gateway, DNS, internet (HTTPS) and whether the switch announces itself.

What the results mean

LinkSpeed and duplex the W5500 negotiated. Half duplex usually means a mismatch.
DHCPTime from link up to lease. Over 5 s is slow; 169.254.x.x means no server answered.
Gateway4 pings to the default gateway.
DNSA lookup sent straight to the server DHCP handed out.
InternetTCP connect on port 443 through this port.

Download .pcap

This is what reaches the port: broadcasts, multicast, traffic to the tester, and flooded unknown-unicast. A switch only sends other devices' private traffic here if the port is mirrored (SPAN). The .pcap holds the last 64 frames, first 128 bytes of each, and opens in Wireshark.

The W5500 has no TDR or wiremap engine. A live Ethernet link, ping time or negotiated speed cannot tell us cable length or certify all four pairs. No length is estimated from packet latency.

 

 
RJ45 pair reference
Pin reference only; these are not measured pair results.

 
Pair 1: pins 1–210/100BASE-TX data

 
Pair 2: pins 3–610/100BASE-TX data

 
Pair 3: pins 4–5Unused for 10/100 data; may carry PoE

 
Pair 4: pins 7–8Unused for 10/100 data; may carry PoE

 
PoE can also share the data pairs. This page cannot detect pair polarity, wire order, split pairs, cable category or shielding.
